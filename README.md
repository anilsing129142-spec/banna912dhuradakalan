# परीक्षा साथी

छोटे विद्यार्थी समूह के लिए हिंदी में बनाया गया निःशुल्क, स्थिर वेबसाइट। इसमें UPSC CSE, CAPF AC, CDS (OTA) और सामान्य अध्ययन के अभ्यास मोड, विषय/अध्याय फिल्टर, टाइमर, स्थानीय प्रगति और उत्तरों की व्याख्या शामिल हैं।

## चलाना

- `index.html` को आधुनिक ब्राउज़र में खोलें। अभ्यास और प्रगति उसी ब्राउज़र में सुरक्षित रहेंगे।
- वेबसाइट को फोन/कंप्यूटर पर इंस्टॉल करने और दोस्तों के साथ URL साझा करने के लिए इसे किसी static hosting पर रखें। वेबसाइट में लॉगिन या सर्वर नहीं है; हर विद्यार्थी की प्रगति उसके अपने ब्राउज़र तक सीमित है।
- फाइलें बिना लागत के static hosting पर रखी जा सकती हैं; उदाहरण के लिए GitHub Pages। इसे सार्वजनिक URL पर डालने के लिए GitHub खाते में repository बनाकर ये फाइलें push करें और repository settings में Pages सक्षम करें।

## सामग्री की सीमा

- प्रश्न बैंक में मौलिक हिंदी अभ्यास प्रश्न हैं; इन्हें आधिकारिक PYQ नहीं कहा गया है। हर विषय के लक्ष्य 1,000 प्रश्न दिखते हैं, लेकिन यह लक्ष्य अभी पूरा नहीं है।
- CAPF Paper II वर्णनात्मक होता है और CDS OTA में अंग्रेज़ी तथा सामान्य ज्ञान के प्रश्नपत्र होते हैं। मौजूदा प्रश्न बैंक अभी सभी इन पेपरों के वास्तविक प्रारूप को कवर नहीं करता।
- अध्ययन सामग्री बाहरी आधिकारिक/विश्वसनीय स्रोतों पर खुलती है; वेबसाइट में किसी पुस्तक या प्रश्नपत्र की अनधिकृत प्रतिलिपि शामिल नहीं है।
- Google Fonts चालू होने पर देवनागरी और लैटिन फ़ॉन्ट के लिए fonts.googleapis.com से अनुरोध किया जाता है; नेटवर्क न हो तो सिस्टम फ़ॉन्ट इस्तेमाल होगा।

## बदली जाने वाली फाइलें

- `app.js`: परीक्षा, टेस्ट प्रवाह, विषय, प्रश्न बैंक आयात/निर्यात और स्रोत लिंक।
- `questions.js`: मौलिक हिंदी अभ्यास प्रश्न।
- 100-प्रश्न मॉक सीरीज़ में 100 क्रमांक उपलब्ध हैं; पूरा मॉक केवल तभी खुलेगा जब चुने हुए टेस्ट में कम से कम 100 प्रश्न हों।
- `styles.css`: रंग, लेआउट और मोबाइल दृश्य।
- `index.html`: पेज संरचना और हिंदी पाठ।

## दूसरे डिवाइस से प्रश्न जोड़ना

अध्ययन सामग्री पेज पर JSON प्रश्न बैंक आयात/निर्यात करें। टेम्पलेट में हर प्रश्न के लिए विषय ID, अध्याय, Hindi/English प्रश्न, चारों विकल्प, सही विकल्प का 0–3 index और दोनों भाषाओं की व्याख्या है। अपने डिवाइस से बैंक निर्यात करके दूसरी डिवाइस पर फ़ाइल आयात की जा सकती है। यह केवल उसी ब्राउज़र में प्रश्न जोड़ता है। सभी विद्यार्थियों को एक साथ नई सामग्री दिखाने के लिए बैंक को प्रकाशित साइट में update करना होगा। बाद में Google Sheets/Firebase जैसा साझा डेटा स्रोत जोड़ा जा सकता है; उसके लिए सेवा खाते और access rules configure करने होंगे।

## सार्वजनिक प्रकाशन

GitHub Pages पर free hosting के लिए GitHub Free में public repository चाहिए। उस स्थिति में source files सबके लिए उपलब्ध होंगी। कोचिंग PDFs सार्वजनिक वेबसाइट में नहीं जोड़ी गई हैं। प्रश्नों में आधिकारिक PYQ और मौलिक अभ्यास को अलग से चिह्नित करना चाहिए; अभी प्रकाशित बैंक मौलिक है। Google में crawl की अनुमति दी गई है (`robots.txt`), लेकिन search result में आना Google की indexing प्रक्रिया पर निर्भर है।
